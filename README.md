# Counter
The Simpliest counter on C with modes and delay.

# About the program
It's a counter, that uses user's delay for delay between counts, and modes. In total, there's 4 modes. 
Modes:
  From positive number to zero
  From zero to positive number

  From negative number to zero
  From zero to negative number

So yeah, it's simple, and because of C, it's **FAST**.

# Downloading
If you want to test program you can clone my repo to your directory, or download and unpack ZIP, check C source code, and launch the program.

## Linux, or other UNIX systems 
Change directory in terminal (or open a terminal in cloned repo) to cloned repo and launch proggram with ./counter.out
